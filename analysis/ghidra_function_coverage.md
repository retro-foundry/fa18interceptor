# Ghidra function-entry coverage

Generated by `scripts/generate_ghidra_function_coverage.py` from every
`pcode/raw/*/functions.json` inventory and exact assembled ranges in
`source_amiga/observed/`.

| Measure | Count | Meaning |
|---|---:|---|
| P-code exports containing a function inventory | 122 | Independent capture packets; entries recur across packets. |
| Distinct Slow-RAM Ghidra function entries | 242 | Union by entry address. All retain Ghidra's `structural` classification. |
| Entries with an exact source-slice entry address | 106 | A readable, byte-exact source slice starts at the same address. This does not imply its entire Ghidra function body is reconstructed. |
| Entries represented within any byte-exact source range | 125 | Includes entries reached through an adjacent source slice. |
| Entries with no byte-exact source representation | 117 | Require source reconstruction or a range extension. |
| Entries with a bounded behavioural routine contract | 31 | Evidence-backed project classifications in `analysis/semantics.json`; this is not a claim that all are exact-entry matches. |
| Entries without an exact source-slice entry | 136 | Either require an entry reconstruction or are represented only by an adjacent source slice. |
