# `$C1B8F8` context command-index selector family

Classification: **structural with byte-exact source**. Six entries set request
bits, branch to prior slot selectors when `D5` is nonzero, or select/adjust
the observed `$C457A7` index through common continuations at `$C1B9CC` and
`$C1B9DA`. The decrement route wraps to `$0B`; the increment route limits at
`$0B`.

The values and request bits are exact. Their player-control bindings require
isolated raw-key traces.
