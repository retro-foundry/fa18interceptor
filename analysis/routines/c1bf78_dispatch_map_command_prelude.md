# `$C1BF78` map-command prelude

Classification: **structural with byte-exact source**. Two entries queue directly. A third context-gated entry sets request bit 0.

When its state flag is nonzero it saves `$C45C42` and retries `$C1B684`; otherwise it saves `D0`, calls `$C0F4A6`, and falls into `$C1BFBC`.
