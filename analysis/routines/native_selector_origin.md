# Native active-origin owner

`port/native_selector_origin.c/.h` implements complete `$C29042` through its
internally reached `$C295D0` paths on ordinary shared native state. The sealed
original instructions are authoritative; `port/game/selector_origin.c`
corroborates the behavior. No lower child contracts remain in this native owner.

The parent runs actual `$C2DAF2` matrix preparation before testing its gates.
The source calls `$C2E370`, whose matrix has full `$4000` scale. The previous
`current_record_matrix.c` used the `$C2E346`/`$100` builder; both that helper and
its mirrored test are corrected. The value entry accepts the live record angle
and original trig data, retaining word subtraction, signed shift by three,
lookup and wrapped sine negation. No record-byte layout is required by this entry.

Actual `$C091A8` snapshots the three input low words and repeats preparation;
`$C091CE` uses the active record's inverse matrix. Both share the actual wrapped
signed products, arithmetic shift by four and record-position translation.
Candidate publication still precedes the wrapped signed floor clamp. Direct
publication preserves the middle origin component, and index rotation and word
scaling retain source widths and signed comparisons.

All nine adjustment modes retain signed thresholds, saved shifts, blending,
small transforms, countdown expiry, smoothing and masked/negated publication.
The root preset reads the same native root record's live position, rather than
requiring a separate tuple. The auxiliary delta is the middle smoothed component:
original `$C45C4E` is `$C45C4A+4`. The owner rejects a detached auxiliary binding.
Mode-seven regeneration invokes the already proved `$C0910C` native starting
position routine, whose original instructions return the fixed original tuple.
`FA18NativeSelectorOriginOps` and its four remaining child families are removed.

The record-update stage requires origin and pose to share the same trig owner,
in addition to its existing shared vector-math and record-bank checks. The actual
magnitude and normalization routines retain source non-completion behavior;
missing data fails explicitly, preserving preceding source-ordered writes.

Validation on 2026-10-05:

- `python tools/recomp/check_native_selector_origin.py`: 65,536 full game-RAM
  comparisons across eight entries, covering 551/551 sealed instruction
  boundaries. All 32,768 parent/matrix calls complete, including 382 actual
  regeneration calls. The core math cases include 1,209 exactly proved original
  zero-factor loops. No substituted children are used.
- All 65,536 record-angle words separately match actual `$C2DAF2/$C2E370/$C2E6DA`
  matrix publication. Full comparisons also verify transform outputs and typed
  aircraft/geometry owners independently of their byte exporter.
- Updated adjustment, pose and region proofs retain their full original scopes.
  Eight affected MSVC Release contract/build checks, strict GNU C11 compilation
  of seven affected units and the unchanged 513-file native guard pass.

`analysis/figures/native_active_selector_origin_checkpoint.json` records exact entries,
reports, coverage and source hashes. CPU, Kickstart and captured RAM are used

are outside this proof's domain. Cold record-list selection `$C29368` is separate.
