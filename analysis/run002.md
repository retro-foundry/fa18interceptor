# Human coverage run 002

`captures/run002/` is a sealed replay from the preserved post-load menu state.
The player selected Base 4 (carrier), took off, and exercised gear, throttle,
weapon fire, chaff, and eject controls. Treat this description as a scenario
index; each code claim requires its recorded event and bounded trace.
