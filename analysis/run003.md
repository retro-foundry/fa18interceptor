## Confirmed input mapping

The first recorded `H` press is frontend `K 104 104 16 1` at frame 1965. It
becomes raw Amiga key `$25`, branches from `$C1AEB8` to `$C1B264`, and toggles
the two-state field `$C457A1`. See
[`c1b264_toggle_hud_mode.md`](routines/c1b264_toggle_hud_mode.md).

The first `M` press becomes raw `$37` and branches to `$C1BF8C`, setting bit 0
of `$C4599C` before entering a long OS/display path. The first `R` press
becomes raw `$13`, branches to `$C1B1C8`, and calls `$C33186`; that child
returns to `$C1B1CE` in 1,924 instructions, where bit 6 of `$C4599A` is set.
The dispatcher packets for both are capped at 1,000 instructions and are
preserved as `pcode/raw/run003_m_key_dispatch/` and
`pcode/raw/run003_r_key_dispatch/`. The bounded R child is
`pcode/raw/run003_r_command_child/`.

The first `T` press becomes raw `$14`, reaches `$C1B1A4`, calls `$C33186`, then
sets `$C4599A` bit 7 and `$C457B9 = 1`; see
[`c1b1a4_request_next_target.md`](routines/c1b1a4_request_next_target.md).
The first `A` press becomes raw `$20`, reaches `$C1B616`, and sets `$C4599A`
bit 1 before its state-dependent shared-helper path.

The first `J` press becomes raw `$26` and executes the ECM toggle at
`$C1C1F2`: it sets `$C4599B` bit 3, writes mode 3 at `$C45840`, and toggles
`$C458B5`. `K` becomes raw `$27`, takes no command branch, and is merely
queued. See [`c1c1f2_toggle_ecm_mode.md`](routines/c1c1f2_toggle_ecm_mode.md).

Comma becomes raw `$38` and selects rudder mask `$80`; period becomes raw
`$39` and selects `$40`. Both replace the high two bits of `$C461E9` and write
the selected value to `$C4582F`. See
[`c1b58e_set_rudder_input_mask.md`](routines/c1b58e_set_rudder_input_mask.md).

`]` becomes raw `$1B` and halves `$C45A42` down to `$20`; `[` becomes raw
`$1A` and doubles it up to `$80`. Both request display update mode 3 and mark
the `$80` endpoint at `$C457DD` bit 7. See
[`c1bae2_adjust_zoom_scale.md`](routines/c1bae2_adjust_zoom_scale.md).

`P` becomes raw `$19` and enters `$C1C06E`, which calls `$C0F4A6` in this
state. Both the dispatcher and a separately isolated helper trace exceed their
instruction caps, so the pause/resume implementation remains unbounded; see
[`c1c06e_pause_command.md`](routines/c1c06e_pause_command.md).

Frontend key code 291 is native F10: the exact restored-state replay produces
raw `$59`, enters the function-key throttle range, derives level ten, and
stores `$79` at `$C45870`. See
[`c1bd04_apply_function_key_throttle_level.md`](routines/c1bd04_apply_function_key_throttle_level.md).

The frontend key-code-0 windows do not reach `$C1AD74`: an isolated replay of
the first recorded tuple (`K 0 0 16 1`) from frame 5,999 fails to hit the raw
key dispatcher through the 24-frame observation window. They are a frontend
recording/mapping limitation in this capture and are not keypad or cursor
evidence.

The run003 `J 0 4` event reaches the established JOY0DAT callback but produces
no sampled hardware delta: the two stored samples and all observed control
accumulators are unchanged, while the callback count increments. It is not
game-axis evidence; see
[`c1718e_joy0dat_callback.md`](routines/c1718e_joy0dat_callback.md).

The first late Space event at frame 7,609 is now independently isolated from a
frame-7,500 restore. It reaches `$C1AD74` on replay frame 114 as raw `$40` and
returns to `$C0F45C` in 64 instructions. Canonical P-code is
`pcode/raw/run003_space_first_dispatch/` (64 starts, 254 operations, one call
target). It calls `$C0833E`, sets `$C4599A` bit 2, then reaches the established
`$C1C23C` common queue tail. In this state `$C461E7` has a zero high nibble, so
the helper returns without writing `$C457BA`; this is a state-dependent
variation from the run002 Space packet, not a changed raw-key mapping.

The first Return event at frame 7,742 is also independently bounded from a
frame-7,700 restore. It reaches `$C1AD74` as raw `$44`, enters `$C1BB7A`, and
returns to `$C0F45C` in 2,042 instructions. The observed default branch calls
`$C33186`, sets `$C4599A` bit 4, cycles the high nibble of `$C461E7` by `$10`
with `$30` wrap, requests value 3 at `$C45843/$C45844`, and clears `$C458B4`.
This is the runtime confirmation of the documented Return weapon-select
control; see [`c1bb7a_cycle_weapon_selection.md`](routines/c1bb7a_cycle_weapon_selection.md).
