# Human coverage run024

`captures/run024/` is a sealed replay from the preserved post-load menu state.
The player reports several failed carrier-qualification attempts followed by a
free-flight pass beneath the Golden Gate Bridge. Those scenario labels are user
context, not yet code-level classifications.

- 1,220 post-setup events; final recorded frame 27,437.
- `playback.e9k` SHA-256: `feca4a90dfbd66093ab445d0abdfe74aa0fc405ce3bb416071d384fb03d0c925`.
- Two independent ordinary replays through frame 27,437 agree on complete
  serialized state, Chip RAM, Slow RAM, registers, cycle count, screenshot /
  video digest, and audio digest. The generated JSON files differ only in their
  wall-clock duration.

  `5c9a50633abaf8a2b76a4f996b5f1b542e7da4f11c18501a48d74f1e111bed27`.

This is evidence for a crashed-flight outcome during run024. It is not, by
itself, evidence that the flight was a qualification attempt: the selected
mission context and any persistent-status mutation remain unproven.

preloaded `QUALIFICATION` buffers at `$C3F309`, `$C3F42E`, or `$C3FAFF`; no
qualification flag or result-state byte is inferred from this display-phase
sample.

## Qualification-screen execution sample

`build/run024_qualification_gate_trace/` replays normally through frame 600,
then instruction-steps chipset frames 601--602 with no future input. It is the
first bounded trace anchored to the visible qualification-gate screen:

- 21,423 instructions; 458 observed Slow-RAM starts; 2,249 exported P-code
  operations; 36 structural call-target candidates.
- The snapshot and trace are byte-validated before Ghidra import. Its visible
  frame-600 video digest is
  `9bcbc0e70de8da2758af1801721564a271f23e6aab4067554b5fe398bed0912`.
- `$C0FECE` is a newly inventoried structural Ghidra entry in this export, but
  it is not among the executed starts in the two-frame interval. No source
  reconstruction, qualification-byte identification, or gameplay name follows
  from this discovery.

The trace is a display-state execution sample, not yet a producer/consumer
trace for persistent qualification status. A future focused capture must put a
breakpoint on a candidate gate reader or trace a transition into/out of this
screen.

The ASCII token `QUALIFICATION` occurs in the trace snapshot's Slow RAM at
`$C3F309`, `$C3F42E`, and `$C3FAFF`. The same text resource is already present
in the preserved baseline snapshot. These are preloaded message bytes, not
candidate qualification-status storage; subsequent work must trace the code
that selects a message rather than treating any of these locations as a flag.
