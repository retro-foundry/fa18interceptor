trace restored from the deterministic run029 replay state at frame 14,200.

structural call targets.  It contributes 754 bytes to the trace-observed union.
It is a positive-run flight execution sample only: it neither proves that a
qualification-success message is absent elsewhere in the recording nor assigns
a persistent qualification-state byte.

The restored state was generated by ordinary replay through frame 14,200.  The
following two frames are stepped and have no input, so the normal trace timing
and held-input/autorepeat caveat applies.
